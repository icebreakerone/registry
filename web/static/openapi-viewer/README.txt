
This is a local copy of swagger-ui, to avoid external dependencies and preserve privacy.

To update:

 * Download latest version from https://github.com/swagger-api/swagger-ui/releases/latest
 * Replace the contents of the 'swagger-ui' directory with the 'dist' directory from the release.
 * Check that the web/static/openapi-viewer/index.html file contains the same path references as the swagger-ui/index.html file.
 * Delete swagger-ui/index.html and swagger-ui/swagger-initializer.js
